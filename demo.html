The main event

Five-minute walkthrough

Everything must already be open. Do not install, log in or configure anything in front of the panel.

  1. 0:00

    Open on the app's Home screen

    Phone in hand, app already signed in. Point out the role-aware bottom navigation and the offline / sync strips at the top.

    "This is the farmer's home. Navigation changes by role, and the strips tell you instantly whether the phone is online and whether anything is waiting to sync."
  2. 0:30

    Farm → Plots tab

    Show Add plot, Harvest records, Livestock and a plot card with its sync badge.

    "Plots are stored locally, so this tab works with no network at all. After our latest fix it keeps working even when the satellite service is unavailable."
  3. 1:30

    Farm → Overview tab

    Show the farm map, plot status card, NDVI gauge and the advice card. If no reading exists, show the Generate satellite data / Try again actions.

    "Crop health: a dated Sentinel-2 reading with a plain-language action, never a bare number. A failed read now stays on this tab with a working retry instead of blanking the whole screen."
  4. 3:00

    One more analysis tab, then the website

    Open Chart, Weather, Growth, Events or Alerts briefly; switch to the website tab on the laptop.

    "Every view answers a farming question and scrolls fully on the phone. The same build is published on this HTTPS page and through the in-app updater."
  5. 4:00

    USSD on any phone

    Run the local simulator and read the CON / END screens aloud (see the section below).

    "And this is how a farmer with a feature phone reaches the same service — no app, no data connection."

Beyond smartphones

USSD — the same service on any GSM phone

Dial *123#. USSD needs no data connection and no app, so it reaches the farmers the Android app cannot.

CON Welcome to AgriConnect 1. Crop health 2. Market prices 3. My plots 4. Record activity 5. Alerts 6. Help 1 → 2 River Plot: NDVI 0.31 (High stress) on 2026-11-12. Check water and weeds. 2 → 2 Sorghum: P 5.10/kg at Gaborone. Indicative only — confirm with the buyer. 4 → 1 → 2 Recorded: Watering on North Plot. It will sync when the phone has data. 00 back to the main menu
Run it locally

The simulator is in Desktop\presentations\USSD\ussd-demo.js and needs no internet. It uses sample data; a live short code needs a gateway account and MSISDN-to-farmer enrolment. Say this plainly if asked.

Be ready for anything

If the network is down

The Plots tab and offline writes still work — demonstrate those first. Show a cached reading and say it keeps its original observation date. The USSD simulator is fully local. Never spend assessment time debugging a connection.
